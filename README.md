# FOLDWORLD

FOLDWORLD is a browser-based paper-map puzzle game. Draw creases and fold the
map to change the board, move through the resulting world, and reach the gate.

## Run locally

```sh
npm ci
npm run dev
```

Create a production build with `npm run build`; preview it with `npm run preview`.

## GitHub Pages

Pushing to `main` builds the static game and deploys it to GitHub Pages through
the workflow in `.github/workflows/pages.yml`.
